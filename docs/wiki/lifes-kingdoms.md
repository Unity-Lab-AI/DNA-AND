## 🦠 Viruses

### Baltimore groups

| | What it is |
|---|---|
| **Double-stranded DNA viruses (group I)** | Example: herpes viruses, pox viruses, many bacteriophages |
| **Single-stranded DNA viruses (group II)** | Example: parvoviruses |
| **Double-stranded RNA viruses (group III)** | Example: rotavirus |
| **Positive-sense RNA viruses (group IV)** | Their RNA can be read straight away like a message. Example: cold viruses, coronaviruses, polio |
| **Negative-sense RNA viruses (group V)** | Their RNA must be copied before it can be read. Example: flu, measles, rabies, Ebola |
| **RNA retroviruses (group VI)** | Write their RNA back into DNA and splice it into the host's own genes. Example: HIV |
| **DNA reverse-transcribing viruses (group VII)** | Example: hepatitis B |

### Shapes and parts

| | What it is |
|---|---|
| **Capsid** | The protein shell around the virus's genes |
| **Envelope** | A fatty outer skin stolen from the last cell it left; some viruses have one, some are naked |
| **Spikes** | Proteins on the surface that latch onto a host cell |
| **Helical virus** | A long spiral rod. Example: tobacco mosaic virus, rabies |
| **Twenty-sided virus** | A round 20-faced shell. Example: herpes, polio |
| **Complex virus** | A head, a tail and legs, or other odd shapes. Example: T4 bacteriophage, pox viruses |
| **Giant virus** | Viruses bigger than some bacteria, with huge genomes. Example: mimivirus |

### Who they infect

| | What it is |
|---|---|
| **Animal viruses** |  |
| **Plant viruses** | Example: mosaic viruses |
| **Bacteriophages** | Viruses that hunt bacteria; the most common biological things on Earth |
| **Archaea viruses** |  |
| **Fungus viruses** |  |

### Life cycles

| | What it is |
|---|---|
| **Lytic cycle** | Inject, copy, burst the cell open, spread |
| **Lysogenic cycle** | Hide inside the host's DNA, copied along with it, until something wakes the virus up |
| **Latency** | Lie dormant in the body for years, then flare up. Example: herpes, chickenpox becoming shingles |

**How it works in the game:**

- Viruses have no cells and no metabolism; they only copy themselves inside a host
- Viruses run on the chemistry layer of the mini AI only: latch on, inject, copy, burst
- RNA viruses mutate fastest; viruses jump between species when they mutate to fit a new host's cells
- Viruses can carry genes from one species into another (Viral Gene Carry power, and natural events)
- A virus can only infect hosts whose cells its spikes can latch onto
- Dense populations let viruses spread fast; immunity, isolation and medicine slow them

## 🔵 Bacteria

### Shapes

| | What it is |
|---|---|
| **Coccus** | A round cell |
| **Bacillus** | A rod-shaped cell |
| **Spirillum** | A stiff spiral cell |
| **Spirochete** | A flexible corkscrew that twists through liquids |
| **Vibrio** | A comma-shaped curved rod |

### Cell parts

| | What it is |
|---|---|
| **Cell wall** | A tough wall around the cell |
| **Flagellum** | A spinning whip tail for swimming |
| **Pili** | Hair-like threads for grabbing surfaces and swapping genes |
| **Capsule** | A slimy outer coat that protects the cell |
| **Plasmid** | A small ring of extra genes that can be passed to other bacteria |
| **Endospore** | A tough sleeping form that survives heat, cold, drying and radiation for years |

### How they get energy and food

| | What it is |
|---|---|
| **Light-eater (photoautotroph)** | Energy from starlight, carbon from carbon dioxide. Example: cyanobacteria |
| **Rock-eater (chemoautotroph)** | Energy from chemicals like sulfur, ammonia or iron |
| **Food-eater (heterotroph)** | Eats other living or dead things |
| **Light-and-food user** | Energy from light, carbon from food |
| **Needs oxygen** |  |
| **Poisoned by oxygen** |  |
| **Either way** | Uses oxygen when it can, switches off when it can't |

### Main groups

| | What it is |
|---|---|
| **Proteobacteria** | Example: E. coli, nitrogen fixers |
| **Cyanobacteria** | The first oxygen makers; built the oxygen air |
| **Firmicutes** | Soil and gut bacteria, many make endospores |
| **Actinobacteria** | Soil bacteria that make many antibiotics |
| **Bacteroidetes** | Gut partners that break down food |
| **Spirochaetes** | Corkscrew swimmers |

### Group life

| | What it is |
|---|---|
| **Biofilm** | A slimy city of bacteria stuck to a surface, tougher together than alone |
| **Quorum sensing** | Bacteria count each other by chemical signal and act together once there are enough |
| **Chemotaxis** | Swimming toward food and away from poison |
| **Stromatolite** | Layered rock mounds built by mats of bacteria over thousands of years |

### Swapping genes

| | What it is |
|---|---|
| **Transformation** | Picking up loose DNA from dead cells |
| **Conjugation** | Passing a plasmid to another bacterium through a pilus |
| **Transduction** | A virus carries genes from one bacterium to another |

**How it works in the game:**

- Bacteria split in two fast; populations explode when food is there and crash when it runs out
- Bacteria trade genes sideways, so useful traits like drug resistance spread fast between species
- Bacteria live everywhere life can, from vents to guts, and recycle everything that dies
- Cyanobacteria fill the air with oxygen over time, triggering the great oxidation and poisoning oxygen-hating life
- Bacteria live inside other life as gut partners, root partners and parasites

## 🟠 Archaea

### What makes them different

| | What it is |
|---|---|
| **Different cell walls** | Archaea walls lack the material bacterial walls are made of |
| **Different cell skin** | Their membranes are built differently, tough enough for boiling and acid |
| **Close cousins of complex cells** | Their gene-reading machinery is more like that of plants and animals than that of bacteria |

### Extremophiles

| | What it is |
|---|---|
| **Heat lover** | Lives near boiling water and above. Example: Methanopyrus, growing at about 98 °C at deep-sea vents |
| **Salt lover** | Lives in water around ten times saltier than the sea |
| **Acid lover** | Example: Sulfolobus, in acidic hot springs |
| **Methane maker** | Makes methane from hydrogen and carbon dioxide, with no oxygen; lives in swamps, guts and sea mud |
| **Cold lover** | Lives in ice and freezing seas |

### Main groups

| | What it is |
|---|---|
| **Euryarchaeota** | Methane makers and salt lovers |
| **Crenarchaeota** | Heat and acid lovers |
| **Thaumarchaeota** | Ammonia eaters in oceans and soil |
| **Asgard archaea** | The closest living relatives of complex cells |

**How it works in the game:**

- Archaea fill the worst places first (vents, acid, salt, ice), so they're often the first life on hard worlds
- An archaean swallowing a bacterium is one route to complex cells (the "swallowed partners" stage)
- Methane makers warm young planets by filling the air with methane

## 🟢 Protists

### Supergroups

| | What it is |
|---|---|
| **Excavates** | Single cells, many with a feeding groove and several whip tails |
| **SAR (stramenopiles, alveolates, rhizarians)** | A huge group: diatoms, brown algae, dinoflagellates, ciliates, the malaria parasite, forams and radiolarians |
| **Archaeplastids** | Life with the first captured chloroplasts: red algae, green algae, and the land plants that grew from them |
| **Amoebozoans** | Amoebas and slime molds that crawl with blunt finger-like arms |
| **Opisthokonts** | Life with a single tail at the back: choanoflagellates, and the fungi and animals that grew from this line |

### Protist groups

| | What it is |
|---|---|
| **Euglenids** | Green swimmers that can both make food from light and eat |
| **Trypanosomes** | Parasites carried by insects |
| **Diatoms** | Drifters in glass shells; make a large share of the oxygen in the seas |
| **Brown algae** | Kelp and big seaweeds |
| **Golden algae** |  |
| **Water molds** | Fungus-like rotters of plants and fish |
| **Dinoflagellates** | Spinning swimmers; some glow, some cause poisonous red tides |
| **Ciliates** | Covered in rows of beating hairs. Example: Paramecium |
| **Apicomplexans** | Parasites that pierce cells. Example: the malaria parasite |
| **Forams** | Tiny shells of chalk that build up into rock over ages |
| **Radiolarians** | Ornate glass skeletons with thin threadlike arms |
| **Red algae** | Seaweeds that grow in deep water |
| **Green algae** | The ancestors of land plants |
| **Amoebas** | Shape-shifting hunters that crawl and engulf food |
| **Slime molds** | Single cells that gather into a crawling body; can solve mazes without a brain |
| **Choanoflagellates** | Collared cells, the closest living relatives of animals |

### How they move

| | What it is |
|---|---|
| **Whip tails (flagella)** |  |
| **Beating hairs (cilia)** |  |
| **Crawling arms (pseudopodia)** |  |
| **Drifting** | Floating with the current |

**How it works in the game:**

- Protists are the first complex cells, with a nucleus and parts inside; they appear after the swallowed-partners stage
- Protist lines lead on: green algae to land plants, choanoflagellate-like cells to animals, opisthokont cells to fungi
- Drifting protists are the base of the sea's food chain; their blooms feed everything, and some blooms poison it
- Chalk and glass shells of dead protists pile up into rock on the sea floor

## 🍄 Fungi

### Phyla

| | What it is |
|---|---|
| **Chytrids** | The only fungi that still swim with a tail; mostly in water; one kind is killing frogs worldwide |
| **Zygomycetes (Mucoromycota)** | Fast molds on fruit and bread. Example: bread mold |
| **Glomeromycetes** | Root partners living inside most plants' roots, trading minerals for sugar |
| **Sac fungi (Ascomycota)** | The biggest group: yeasts, molds, morels and truffles |
| **Club fungi (Basidiomycota)** | Mushrooms with gills, puffballs, and the rusts and smuts that attack crops |

### Body parts

| | What it is |
|---|---|
| **Hypha** | A thin thread, the basic body of a fungus |
| **Mycelium** | A hidden web of threads through soil, wood or flesh; one can spread for kilometers |
| **Fruiting body** | The mushroom or cup that pops up to release spores |
| **Spores** | Tiny seeds of a fungus, carried by wind, water and animals |
| **Gills** | The thin plates under a mushroom cap where spores are made |

### Ways of living

| | What it is |
|---|---|
| **Decomposer** | Rots dead plants and animals back into soil |
| **Root partner (mycorrhiza)** | Wraps or enters plant roots, trading water and minerals for sugar; links plants into networks |
| **Lichen** | A fungus and an alga living as one, able to grow on bare rock |
| **Parasite** | Feeds on living plants, insects or animals |
| **Body-snatching fungus** | Takes over an insect's behavior before killing it |
| **Yeast** | Single-celled fungi that ferment sugar into alcohol and gas |

**How it works in the game:**

- Fungi rot what dies and return it to the soil; without them dead matter piles up
- Root-partner fungi link plants underground, sharing food and warnings (the root-network step on the grouping ladder)
- Fungi spread by spores on wind and water, and by growing their mycelium through soil and wood
- Root-partner fungi help the first plants move onto land
- Fungi can be farmed: by ants and termites, and by thinking species for food, drugs and fermenting

## 🌿 Plants

### Groups

| | What it is |
|---|---|
| **Liverworts** | Flat, leafy, damp-ground plants with no veins; among the first on land |
| **Mosses** | Soft carpets with no veins; need water to breed |
| **Hornworts** | Small plants with horn-shaped spore stalks |
| **Club mosses and spike mosses** | Ancient spore plants with veins; once giant trees in coal-age swamps |
| **Ferns and horsetails** | Spore plants with veins and big fronds or jointed stems |
| **Cycads** | Palm-like seed plants with cones |
| **Ginkgo** | One living species left, a living fossil tree |
| **Conifers** | Pines, firs, spruces, cedars and redwoods; needles and cones |
| **Gnetophytes** | A small, strange group of seed plants |
| **Flowering plants** | By far the biggest group, over 380,000 species: flowers, enclosed seeds, fruit |

### Big splits

| | What it is |
|---|---|
| **Plants without veins** | Mosses, liverworts, hornworts; small, close to the ground, need damp |
| **Plants with veins** | Tubes carry water up and food down, so they can grow tall |
| **Spore plants** | Breed with spores, not seeds |
| **Naked-seed plants** | Gymnosperms: seeds on cones, not inside fruit |
| **Enclosed-seed plants** | Flowering plants: seeds grow inside fruit |

### Organs and tissues

| | What it is |
|---|---|
| **Roots** | Anchor the plant and drink water and minerals |
| **Rhizoids** | Simple root-like threads on mosses and liverworts |
| **Stem** | Holds the plant up and carries water and food |
| **Leaves** | Catch starlight and make food |
| **Flower** | The breeding part, often built to lure pollinators |
| **Seed** | A baby plant packed with food in a tough coat |
| **Fruit** | Wraps the seeds, often to be eaten and carried away by animals |
| **Xylem** | Tubes carrying water up from the roots; in trees it becomes wood |
| **Phloem** | Tubes carrying food from the leaves to the rest of the plant |
| **Bark** | The protective skin of woody stems |
| **Thorns and spines** | Defense against eaters |

### How they make food

| | What it is |
|---|---|
| **Standard photosynthesis (C3)** | The most common way; works best in mild, damp places |
| **Hot-climate photosynthesis (C4)** | Concentrates carbon dioxide to work in heat and bright light. Example: corn, sugarcane, many grasses |
| **Desert photosynthesis (CAM)** | Opens its pores only at night to save water. Example: cacti, agave, pineapple |
| **Plant parasites** | Some plants steal food from other plants instead of making their own |
| **Carnivorous plants** | Trap insects for extra nutrients. Example: Venus flytrap, pitcher plants |

### How they breed

| | What it is |
|---|---|
| **Alternation of generations** | Plants swap between a spore-making form and a sex-cell-making form each generation |
| **Spores** |  |
| **Pollen** | Carried by wind, insects, birds or bats |
| **Seeds** |  |
| **Runners and cloning** | Copies of themselves from roots, runners or broken pieces |

**How it works in the game:**

- Plants climb onto land from green algae, with root-partner fungi helping; veins let them grow tall; seeds free them from water
- Climate decides the kind: C3 in mild damp places, C4 in hot grasslands, CAM in deserts
- Forests make soil and air, and when buried they become coal
- Flowering plants and pollinators evolve together; fruit evolves with the animals that spread it
- Plants fight back with thorns, poisons, bark and chemical warnings to their neighbors
- Thinking species farm, breed and engineer plants (Farming, Selective Breeding, Genetic Engineering)

## 🐾 Animals

### Body-plan traits

| | What it is |
|---|---|
| **No symmetry** | Example: sponges, placozoans |
| **Radial symmetry** | A round body with parts arranged around a center. Example: jellyfish, corals |
| **Bilateral symmetry** | A left and right side, a front and back, a head end |
| **Two tissue layers** | Example: jellyfish, comb jellies |
| **Three tissue layers** | Allows muscles and organs |
| **No body cavity** | Example: flatworms |
| **Partial body cavity** | Example: roundworms, rotifers |
| **True body cavity** | Example: mollusks, arthropods, echinoderms, chordates |
| **Segmented body** | Example: earthworms, insects, vertebrate spines |
| **Molting** | Sheds its outer skin to grow (the molting branch: roundworms, arthropods, water bears) |
| **Mouth-first development** | The first opening in the embryo becomes the mouth (protostomes) |
| **Anus-first development** | The first opening becomes the anus (deuterostomes: echinoderms, chordates) |

**How it works in the game:**

- Every animal's body comes from its genes: symmetry, layers, body cavity, segments, skeleton, limbs, eyes, skin
- New animals branch from real lines: phylum, then class, order, family, genus, species, each filling to 100 in play with invented ones
- Unrelated lines can evolve the same answer (wings, eyes, fins), because the same problems shape them
- Any line can climb to intelligence: primates, wolves, crows, parrots, octopuses, whales, social insects (the grouping ladder)
- Lines die out; extinct groups like trilobites and dinosaurs stay greyed out on the tree forever

## 🧠 Minds

### Real thinking animals

| | What it is |
|---|---|
| **Great apes** | Tool use, culture, self-recognition, sign-language learning in captivity, politics and war |
| **Humans** | Language, writing, technology, civilization; the only species known to reach space |
| **Crows and ravens** | Tool making, planning ahead, solving puzzles, recognizing faces; minds that evolved separately from apes' |
| **Parrots** | Speech, counting, problem solving |
| **Dolphins and whales** | Self-recognition, names (signature whistles), culture passed between groups, songs |
| **Elephants** | Self-recognition, mourning their dead, long memory, family culture |
| **Octopuses** | Problem solving, escape, camouflage; a smart line with no social life and short lives |
| **Wolves and dogs** | Pack hunting strategy, reading faces and gestures |
| **Magpies** | One of the few birds reported to pass the mirror test |
| **Cleaner wrasse** | A small fish reported to pass the mirror test |
| **Social insects** | No single smart brain, but colonies that solve problems together: farming, building, war, voting on new nests |
| **Slime molds** | With no brain at all, they solve mazes and find the shortest paths |

### Signs of a mind

| | What it is |
|---|---|
| **Tool use** |  |
| **Tool making** |  |
| **Self-recognition** | Knowing yourself in a mirror; one test of a mind |
| **Planning ahead** |  |
| **Language** |  |
| **Culture** | Ways of doing things taught, not born with |
| **Mourning** |  |
| **Deception** |  |
| **Teaching** |  |
| **Collective mind** | Many small minds acting as one (hives, swarms) |

### What pushes a line toward intelligence

| | What it is |
|---|---|
| **Living in groups** | Tracking friends, rivals and debts takes a bigger brain |
| **Grasping limbs** | Hands, trunks, beaks, tentacles that can handle tools |
| **Long life and long childhood** | More time to learn and to teach |
| **Hard-to-get food** | Nuts, shellfish, prey that must be outwitted |
| **Big brain for its body** | Brain size compared to body size is one rough sign, but not the only one |
| **A changing world** | Fast-changing climates reward clever, flexible animals |
| **Many roads to a mind** | Crows, apes and octopuses reached cleverness separately; minds evolve again and again |

**How it works in the game:**

- Any kingdom can reach intelligence if evolution builds the drivers: animals most often, but hive insects, fungal networks and even plants on other templates can climb the grouping ladder
- A species earns signs of a mind one by one (tool use, culture, language…); together they unlock the thinking steps (31+) on the grouping ladder
- A thinking species' clothing, tools, cities and ships are generated from its own body plan
- Thinking species get the species AI layer, and can later grow a galactic mind
- The Spark of Mind power pushes a species toward intelligence, but only works on one already close to it
