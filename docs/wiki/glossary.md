# 📚 Glossary

[🏠 Wiki home](README.md)

Every highlighted word in the wiki links here.

---

| Term | Meaning |
|---|---|
| <a id="age"></a>🏺 **Age** | One step in a civilization's history, like the Bronze Age. There are 100. See [Ages of Civilization](ages-of-civilization.md). |
| <a id="asexual"></a>🧫 **Asexual** | Making young from one parent, by copying itself. |
| <a id="biome"></a>🌳 **Biome** | A kind of environment, like desert, rainforest or tundra. |
| <a id="civilization"></a>🏛️ **Civilization** | Intelligent life living together with culture, politics, technology and war. |
| <a id="cooldown"></a>⏳ **Cooldown** | Wait time before one of the 20 strongest powers (T81–T100) can be used again. |
| <a id="dna"></a>🧬 **DNA** | The four-letter code (A, C, G, T) that builds every living thing. |
| <a id="dyson-sphere"></a>🌞 **Dyson sphere** | A giant shell of machines built around a star to catch all its energy. |
| <a id="element"></a>⚗️ **Element** | One of the 118 basic building blocks of matter. See [Elements](elements.md). |
| <a id="evolution"></a>🔁 **Evolution** | Life changing over generations as genes mutate, mix and get passed on. |
| <a id="extinction"></a>💀 **Extinction** | When the last of a species dies. |
| <a id="flocking"></a>🐦 **Flocking** | All things flock together: every kind of life groups up, step by step. See [Groups & Flocking](groups-and-flocking.md). |
| <a id="galactic-mind"></a>🌌 **Galactic mind** | The top AI layer: one will steering life across a whole galaxy. |
| <a id="galaxy"></a>🌌 **Galaxy** | A huge group of solar systems. You can reach more than one. |
| <a id="gene"></a>🧩 **Gene** | One piece of DNA that gives a trait or skill. |
| <a id="gene-map"></a>🗺️ **Gene map** | The panel showing which gene pieces give which traits. |
| <a id="genebank"></a>🏦 **Genebank** | The shared library of players on the leaderboard. The weekly top three (Genome of the Week) can upload a genome for others to use. |
| <a id="genome"></a>📜 **Genome** | The full set of DNA instructions for one living thing. |
| <a id="genome-of-the-week"></a>🏅 **Genome of the Week** | The weekly top three on the leaderboard, who get to upload a genome to the Genebank. |
| <a id="grouping-ladder"></a>🪜 **Grouping ladder** | The 100 steps every kind of life can climb, from one lone creature to life that spans the universe. |
| <a id="harvest"></a>🌾 **Harvest** | Reaping living things directly for souls. Slow, and it scares intelligent life. |
| <a id="hive-mind"></a>🐝 **Hive mind** | A colony that thinks and acts as one. |
| <a id="host"></a>🖥️ **Host** | The player whose computer runs a shared multiplayer world. |
| <a id="intelligent-life"></a>🧠 **Intelligent life** | Species smart enough to build tools, cultures and civilizations. |
| <a id="invasive"></a>🦖 **Invasive species** | Life that arrives somewhere new and takes over. |
| <a id="meteorite"></a>☄️ **Meteorite** | A space rock that lands. It's also how Genebank genomes arrive in your world. |
| <a id="milestone"></a>🏁 **Milestone** | A big step in evolution or history, like the first walk or the first fire. Time slows down so you can see it. |
| <a id="mini-ai"></a>🧠 **Mini AI** | The little mind every living thing runs, in layers: chemistry, individual, group, hive, species, galactic mind. |
| <a id="mutation"></a>🎲 **Mutation** | A random change in DNA. |
| <a id="photosynthesis"></a>🌿 **Photosynthesis** | Making food from starlight. |
| <a id="planet"></a>🪐 **Planet** | A world that circles a star. Life can live on it. |
| <a id="power"></a>⚡ **Power** | One of your 100 god abilities. Each costs souls. See [God Powers](god-powers.md). |
| <a id="sanctuary"></a>🛡️ **Sanctuary** | A power that protects an area from your other powers and from disasters. |
| <a id="seed"></a>🎲 **Seed** | The number that builds your world. Same seed, same galaxy. |
| <a id="selfish-gene"></a>😈 **Selfish gene** | The drive inside all life: get more, do more and pass your genes on before you die. |
| <a id="solar-system"></a>☀️ **Solar system** | A star and the planets around it. |
| <a id="souls"></a>👻 **Souls** | The energy you spend on god powers. Life gives them off; deaths and harvesting give more. |
| <a id="species"></a>🐾 **Species** | One kind of living thing. |
| <a id="stage"></a>🦠 **Stage** | One step in the story of life, like First Cells or Life on Land. There are 100. See [Stages of Life](stages-of-life.md). |
| <a id="tech-tree"></a>🔬 **Tech tree** | Everything intelligent life can discover, and what leads to what. See [Tech Tree](tech-tree.md). |
| <a id="template"></a>🌍 **Template** | A planet type with its own rules. Earth comes first; the others unlock as you play. |
| <a id="trait"></a>✨ **Trait** | Something a creature has or can do, like eyes, fur or flight. |
| <a id="tree-of-life"></a>🌳 **Tree of Life** | The circular family tree and gene tree of every species in your game. See [Tree of Life](tree-of-life.md). |
| <a id="virus"></a>🦠 **Virus** | A tiny thing with its own genome that lives by infecting others. It can carry genes between species. |
