# 📚 Glossary

[🏠 Wiki home](README.md)

Every highlighted word in the wiki links here. **100 terms**, A to Z.

---

| Term | Meaning |
|---|---|
| <a id="adult-rating"></a>🔞 **18+** | DNA-AND is for adults. Life does everything real life does, from sex to killing and murder. |
| <a id="accessibility"></a>♿ **Accessibility** | Settings that make the game easier to see, read and play: colorblind modes, text size, subtitles, reduced motion. |
| <a id="age"></a>🏺 **Age** | One step in a civilization's history, like the Bronze Age. There are 100. See [Ages of Civilization](ages-of-civilization.md). |
| <a id="ancestor"></a>👴 **Ancestor** | A living thing that later species came from. Your first cell is the ancestor of everything. |
| <a id="asexual"></a>🧫 **Asexual** | Making young from one parent, by copying itself. |
| <a id="asteroid"></a>🪨 **Asteroid** | A rock circling a star. Good for mining, bad when it hits. |
| <a id="autosave"></a>💾 **Autosave** | The game saves itself every 10 minutes and at every headline milestone. |
| <a id="bacteria"></a>🦠 **Bacteria** | Single cells without a nucleus. Among the first life, and still everywhere. |
| <a id="biome"></a>🌳 **Biome** | A kind of environment, like desert, rainforest or tundra. |
| <a id="black-hole"></a>⚫ **Black hole** | A collapsed star whose pull nothing escapes. |
| <a id="chemistry-ai"></a>🧪 **Chemistry AI** | The mini AI of brainless life: sense something, then respond. |
| <a id="civilization"></a>🏛️ **Civilization** | Intelligent life living together with culture, politics, technology and war. |
| <a id="colony"></a>🏘️ **Colony** | A group living together, from a microbe colony to a settlement on another world. |
| <a id="comet"></a>☄️ **Comet** | A ball of ice and dust from the edge of a solar system. It can bring water, or extinction. |
| <a id="cooldown"></a>⏳ **Cooldown** | Wait time before one of the 20 strongest powers (T81–T100) can be used again. |
| <a id="cost"></a>💸 **Cost** | What a power takes in souls: tier × area × strength. |
| <a id="dark-harvest"></a>🩸 **Dark Harvest** | The 100 cruelest ways civilizations harvest life for you. See [The Dark Harvest](dark-harvest.md). |
| <a id="dna"></a>🧬 **DNA** | The four-letter code (A, C, G, T) that builds every living thing. |
| <a id="domain"></a>🌐 **Domain** | The biggest rank in the Tree of Life, above kingdom. |
| <a id="dyson-sphere"></a>🌞 **Dyson sphere** | A giant shell of machines built around a star to catch all its energy. |
| <a id="ecosystem"></a>🌿 **Ecosystem** | All the life in one place and how it connects. |
| <a id="element"></a>⚗️ **Element** | One of the 118 basic building blocks of matter. See [Elements](elements.md). |
| <a id="evolution"></a>🔁 **Evolution** | Life changing over generations as genes mutate, mix and get passed on. |
| <a id="extinction"></a>💀 **Extinction** | When the last of a species dies. |
| <a id="family-tree"></a>👪 **Family tree** | The Tree of Life view showing who descended from whom. |
| <a id="flocking"></a>🐦 **Flocking** | All things flock together: every kind of life groups up, step by step. See [Groups & Flocking](groups-and-flocking.md). |
| <a id="food-chain"></a>🍽️ **Food chain** | Who eats whom. |
| <a id="galactic-mind"></a>🌌 **Galactic mind** | The top AI layer: one will steering life across a whole galaxy. |
| <a id="galaxy"></a>🌌 **Galaxy** | A huge group of solar systems. You can reach more than one. |
| <a id="galaxy-size"></a>📏 **Galaxy size** | Small, Medium, Large or Massive. You pick it for a new world. |
| <a id="gene"></a>🧩 **Gene** | One piece of DNA that gives a trait or skill. |
| <a id="gene-map"></a>🗺️ **Gene map** | The panel showing which gene pieces give which traits. |
| <a id="gene-tree"></a>🧬 **Gene tree** | The Tree of Life view showing where each gene came from and how it spread. |
| <a id="genebank"></a>🏦 **Genebank** | The shared library of players on the leaderboard. The weekly top three (Genome of the Week) can upload a genome for others to use. |
| <a id="genome"></a>📜 **Genome** | The full set of DNA instructions for one living thing. |
| <a id="genome-of-the-week"></a>🏅 **Genome of the Week** | The weekly top three on the leaderboard, who get to upload a genome to the Genebank. |
| <a id="grouping-ladder"></a>🪜 **Grouping ladder** | The 100 steps every kind of life can climb, from one lone creature to life that spans the universe. |
| <a id="grouping-step"></a>🪜 **Grouping step** | One of the 100 steps on the grouping ladder, like pack, tribe or city. |
| <a id="habitat"></a>🏡 **Habitat** | Where a species lives. |
| <a id="harvest"></a>🌾 **Harvest** | Reaping living things directly for souls. Slow, and it scares intelligent life. |
| <a id="heredity"></a>🧬 **Heredity** | Passing genes from parents to young. |
| <a id="hive"></a>🐝 **Hive** | A colony that works as one body, with castes like workers and soldiers. |
| <a id="hive-mind"></a>🐝 **Hive mind** | A colony that thinks and acts as one. |
| <a id="horde"></a>🐺 **Horde** | A huge mass of one kind, like a wolf horde. Step 19 on the grouping ladder. |
| <a id="host"></a>🖥️ **Host** | The player whose computer runs a shared multiplayer world. |
| <a id="intelligent-life"></a>🧠 **Intelligent life** | Species smart enough to build tools, cultures and civilizations. |
| <a id="invasive"></a>🦖 **Invasive species** | Life that arrives somewhere new and takes over. |
| <a id="join-code"></a>🔑 **Join code** | The code the host shares so friends can join a world. |
| <a id="kingdom"></a>👑 **Kingdom** | A rank in the Tree of Life (animals, plants, fungi…), or a ruled realm in civilization. |
| <a id="leaderboard"></a>🏆 **Leaderboard** | The world ranking. Score = life in your galaxy + life harvested. |
| <a id="lightning"></a>⚡ **Lightning** | A starter power. One strike can spark the chemistry of life. |
| <a id="meteorite"></a>☄️ **Meteorite** | A space rock that lands. It's also how Genebank genomes arrive in your world. |
| <a id="microbe"></a>🔬 **Microbe** | Any living thing too small to see. |
| <a id="milestone"></a>🏁 **Milestone** | A step in evolution or history. Every stage has 100, and its headline one completes the stage, like the first walk or the first fire. Time slows down so you can see it. |
| <a id="mini-ai"></a>🧠 **Mini AI** | The little mind every living thing runs, in layers: chemistry, individual, group, hive, species, galactic mind. |
| <a id="moon"></a>🌙 **Moon** | A world circling a planet. Its pull makes tides. |
| <a id="mutation"></a>🎲 **Mutation** | A random change in DNA. |
| <a id="nebula"></a>🌫️ **Nebula** | A glowing cloud of gas where new stars are born. |
| <a id="nudge"></a>🤏 **Nudge** | Changing the world around intelligent life so they choose differently. You never command them. |
| <a id="nutrient"></a>🥗 **Nutrient** | Something life needs to grow, like nitrogen, phosphorus or sugar. |
| <a id="orbit"></a>🔄 **Orbit** | The path of a planet around a star, or a moon around a planet. |
| <a id="oxygen"></a>🫧 **Oxygen** | The gas that early life made, and later life breathes. |
| <a id="ozone"></a>🛡️ **Ozone** | A high layer of gas that shields land life from harsh starlight. |
| <a id="pack"></a>🐺 **Pack** | A small hunting group of one kind. Step 11 on the grouping ladder. |
| <a id="parasite"></a>🪱 **Parasite** | Life that lives on or in another and feeds on it. |
| <a id="photosynthesis"></a>🌿 **Photosynthesis** | Making food from starlight. |
| <a id="planet"></a>🪐 **Planet** | A world that circles a star. Life can live on it. |
| <a id="power"></a>⚡ **Power** | One of your 100 god abilities. Each costs souls. See [God Powers](god-powers.md). |
| <a id="predator"></a>🦁 **Predator** | A hunter. |
| <a id="prey"></a>🦌 **Prey** | The hunted. |
| <a id="quorum-sensing"></a>📡 **Quorum sensing** | How bacteria "vote" with chemical signals, then act all at once. |
| <a id="rank"></a>🏷️ **Rank** | A level in the Tree of Life: domain, kingdom, phylum, class, order, family, genus, species. |
| <a id="sanctuary"></a>🛡️ **Sanctuary** | A power that protects an area from your other powers and from disasters. |
| <a id="save-slot"></a>📂 **Save slot** | A saved world. Slots are unlimited. |
| <a id="seed"></a>🎲 **Seed** | The number that builds your world. Same seed, same galaxy. |
| <a id="selfish-gene"></a>😈 **Selfish gene** | The drive inside all life: get more, do more and pass your genes on before you die. |
| <a id="society"></a>🗳️ **Society** | How a thinking species rules, trades, lives, believes and keeps order. There are 100 kinds. |
| <a id="solar-system"></a>☀️ **Solar system** | A star and the planets around it. |
| <a id="souls"></a>👻 **Souls** | The energy you spend on god powers. Life gives them off; deaths and harvesting give more. |
| <a id="species"></a>🐾 **Species** | One kind of living thing. |
| <a id="speed"></a>⏩ **Speed** | Pause, 1×, 10×, 100×, 1,000× or max. |
| <a id="stage"></a>🦠 **Stage** | One step in the story of life, like First Cells or Life on Land. There are 100. See [Stages of Life](stages-of-life.md). |
| <a id="star"></a>⭐ **Star** | A burning ball of gas at the heart of a solar system. Ours is called the Sun. |
| <a id="starlight"></a>✨ **Starlight** | Light from a star. Plants turn it into food. |
| <a id="starter-toolkit"></a>🧰 **Starter toolkit** | What you have on day one: Fire, Cold, Water, Lightning, Spark of Life, adding genes and adding elements. |
| <a id="stellar-flare"></a>🌞 **Stellar flare** | A burst from a star that fries technology. |
| <a id="supernova"></a>💥 **Supernova** | An exploding star. |
| <a id="swarm"></a>🦗 **Swarm** | A huge moving mass of small creatures. Step 18 on the grouping ladder. |
| <a id="symbiosis"></a>🤝 **Symbiosis** | Two species living closely together, often helping each other. |
| <a id="tech-tree"></a>🔬 **Tech tree** | Everything intelligent life can discover, and what leads to what. See [Tech Tree](tech-tree.md). |
| <a id="template"></a>🌍 **Template** | A planet type with its own rules. Earth comes first; the others unlock as you play. |
| <a id="terraforming"></a>🌍 **Terraforming** | Reshaping a whole planet so life can live there. |
| <a id="tier"></a>🏷️ **Tier** | T1 to T100: every power ranked from weakest to strongest. A higher tier costs more. |
| <a id="trait"></a>✨ **Trait** | Something a creature has or can do, like eyes, fur or flight. |
| <a id="tree-of-life"></a>🌳 **Tree of Life** | The circular family tree and gene tree of every species in your game. See [Tree of Life](tree-of-life.md). |
| <a id="tribe"></a>🏕️ **Tribe** | Kin groups living together with shared customs. Step 36 on the grouping ladder. |
| <a id="unlock-point"></a>🔓 **Unlock point** | The stage of life where a power opens. Each of the 100 stages is one. |
| <a id="village"></a>🏘️ **Village** | A settled group with homes and fields. Step 44 on the grouping ladder. |
| <a id="virus"></a>🦠 **Virus** | A tiny thing with its own genome that lives by infecting others. It can carry genes between species. |
| <a id="wormhole"></a>🌀 **Wormhole** | A shortcut through space. |
