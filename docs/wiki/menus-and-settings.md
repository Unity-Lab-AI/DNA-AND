## 🏠 Main menu

| | Button | What it does |
|:-:|---|---|
| 🌱 | **New World** | Pick a seed (or random) and a galaxy size, and start |
| 📂 | **Continue / Load** | Pick up where you left off, from your save slots |
| 🤝 | **Multiplayer** | Host or join a shared world |
| 🏆 | **Genebank + Leaderboard** | Top players and their uploaded genomes |
| 📖 | **Wiki** | This wiki, inside the game |
| ⚙️ | **Settings** | Make the game yours |
| 💜 | **Credits** | The people who made it |
| 🚪 | **Quit** | See you soon |

🔞 The main menu shows the game's **18+** rating.

---

## 💾 Saving

Your world saves to save slots, so you can keep several galaxies going at once.

⏱️ **Autosave** runs every 10 minutes and at every headline milestone. Save slots are unlimited.

---

## ⚙️ Settings

| Group | What's in it |
|---|---|
| 🖼️ **Graphics** | Resolution, render scale (draw at 50% to 200% of the window: lower is faster, higher is sharper), quality, detail distance |
| 🔊 **Sound** | Master, music, nature, effects |
| 🎮 **Controls** | Rebind keys, mouse speed, edge panning on/off |
| ⏱️ **Gameplay** | Milestone slow-downs and cinematics on/off, tooltips on/off |
| 🌐 **Online** | Leaderboard and Genebank on/off |
| ♿ **Accessibility** | Colorblind modes, text size, subtitles, reduced motion |

---

## ⏸️ In-game menu

Press **Esc** any time to pause and open the menu: resume, save, load, wiki, settings, quit to main menu.
